## Hypothesis

Per a widely-cited r/algotrading summary of Larry Connors' public RSI
mean-reversion rule set: buy when price is above its 200-day SMA (uptrend
intact) AND RSI(4) crosses below 30 (sharp short-term pullback); exit
purely when RSI crosses above 55 (fixed level, not moving-average
recovery). This is structurally distinct from this repo's already-accepted
RSI(2)/SMA(5)-recovery-exit variant (id=2026-09-03-005) via the exit
mechanism (pure RSI level vs SMA-recovery) and from the already-rejected
RSI(10) 55/45 momentum-continuation variant (id=2026-09-04-077) via using
RSI as an oversold-mean-reversion trigger rather than a momentum-
continuation trigger.

Source: r/algotrading thread (public knowledge summary of Connors' rule,
see visited_pages.jsonl entry this iteration).

## Step 8 — Decision: REJECT

Full-sample Sharpe fails decisively on BOTH equities (0.73/0.85 vs the 1.0
threshold), despite a strong low-vol-regime-only Sharpe (2.42) surfaced by
the grid. This is a textbook case of the grid's low-vol slice
over-representing the strategy's true full-sample edge -- most of the
alpha concentrates in calm markets and gets diluted/reversed once mid/high
vol periods (worst cell Sharpe -0.42) are included in the full sample. SPY
additionally fails walk-forward (only 2/4 splits with positive Sharpe).
MDD, transaction-cost-survival, and parameter-sensitivity all pass, so this
is not a fundamental flaw (execution/robustness are fine) -- it's a
genuine edge-doesn't-clear-the-full-sample-bar rejection, same pattern as
several other Connors-RSI-family entries already logged in this repo.

Crypto rejected decisively (0/72 grid cells) -- not tested further with
single-config validators (compute-cost scope limitation, consistent with
this repo's standard practice for decisive 0% grid slices).

The strategy file and this report are kept as a record of a rejected
attempt (not a live strategy).
