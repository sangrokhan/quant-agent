# Backtest Report: RSI(5) 30-50 Pullback (2026-09-26)

**Strategy file:** `strategies/2026-09-26_rsi5_30_50_pullback.py`
**KB id:** 2026-09-26-014

## Hypothesis

Per QuantifiedStrategies.com's "RSI 30 50 Strategy for Beginners"
(https://quantifiedstrategies.substack.com/p/rsi-30-50-strategy-for-beginners,
free, fully disclosed rule): in an uptrend (close>SMA(200)), RSI(5)
dropping below 30 marks a pullback (not a reversal) worth buying; sell
when RSI(5) recovers to >=50. Source's own S&P 500 backtest: 196 trades,
81% win rate, profit factor 3, CAGR 5.3%, only 11% time-in-market, MDD -15%.
Distinct from all other RSI(2)-family entries in this repo (45+ prior
hits) — this specific RSI(5)/30-in/50-out combination has 0 prior hits.

A full local 9-cell sweep of the full 2016-2026 sample on QQQ and SPY

## Decision

**REJECT (all symbols, all tested configs)**. Similar to this cron
trigger's earlier RSI(2)-NATR test, the low-vol-tercile grid slice
surfaced an attractive Sharpe (1.88 on QQQ), but this does not survive
full-sample validation — the best any config achieves full-sample is
0.734 (QQQ), well short of the 1.0 threshold. Source's own disclosed
"risk-adjusted return: 44% (CAGR divided by time-in-market)" metric is not
directly comparable to this repo's annualized-Sharpe validator bar, and
appears to overstate the edge relative to a standard Sharpe calculation.
Crypto decisively fails (0/54 grid cells) — a fixed RSI(5) 30/50 zone
doesn't transfer to crypto's different volatility character. No new
external source needed to confirm this is a clean rejection, so the
remaining validator suite (MDD/TC/walk-forward/param-sensitivity) was
skipped per RESEARCH_LOOP.md Step 7 guidance.
